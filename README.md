# banking-system
A RESTful Banking System built with Java, Spring Boot, Spring Security, JWT, and MySQL.
A RESTful Banking System application built with Java and Spring Boot. This project demonstrates backend development concepts, including REST APIs, database management, authentication, authorization, and transaction processing.

Technologies Used

Java

Spring Boot

Spring Security

JSON Web Tokens (JWT)

Spring Data JPA

Hibernate

MySQL

Maven

Bean Validation

Lombok

Features

Customer Management

Create new customers.

Retrieve customer information.

Update customer information.

Delete customers.

Check whether a customer exists.

Bank Account Management

Create bank accounts.

Retrieve bank account information.

Update bank account details.

Support checking and savings accounts.

Associate bank accounts with customers.

Transaction Management

Deposit money into an account.

Withdraw money from an account.

Transfer money between bank accounts.

Check account balances.

Prevent withdrawals when the account has insufficient funds.

Maintain transaction records.

Authentication and Security

User registration and login.

Password encryption.

JWT-based authentication.

Spring Security integration.

Additional Features

Centralized exception handling.

Request validation.

Custom exception classes.

Application logging.

Audit and performance logging using Spring AOP.

Database

This application uses MySQL for data persistence.

Main entities:

Customer

BankAccount

Transaction

User
Note: This is a demonstration application. It does not process real money or connect to actual banking institutions.
